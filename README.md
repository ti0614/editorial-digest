# 社説まとめツール (editorial-digest)

新聞各社の社説（オピニオン）一覧ページを巡回し、タイトル・リンク・日付を
Markdown/JSON でまとめて出力する CLI ツールです。

## できること / できないこと

- 取得するのは **タイトル・記事URL・日付のみ** です。本文（著作権のある
  記事全文）は取得・保存しません。まとめを読んだ後、リンク先の元記事を
  各紙のサイトで読む形を想定しています。
- 取得前に対象ページの `robots.txt` を確認し、許可されていない場合は
  自動的にスキップします。
- 1件ごとの取得の間に待機時間（既定2秒）を入れ、サイトへの負荷を抑えます。

## 重要な注意（必ず読んでください）

- **本ツールはこのビルド環境（サンドボックス）から各新聞社サイトへの
  ネットワークアクセスができない状態で作成しました。** そのため
  `sources.yaml` に設定した CSS セレクタ・URL は学習知識に基づく
  「たたき台」であり、実機で動作確認できていません（各項目
  `verified: false`）。
- 実際に使う前に、ネットワークアクセス可能な環境（自分のPC・CI等）で
  `python main.py check` を実行し、各紙が正しく取得できるか確認・
  修正してください。サイトリニューアルで HTML 構造が変わっている
  可能性が高いです。
- 各新聞社の利用規約でクローリング・自動取得が禁止/制限されている
  場合があります。本ツールは robots.txt に従いますが、それとは別に
  各サイトの利用規約も確認し、私的利用の範囲内でお使いください。
  商用利用・二次配布・記事本文の再配布は想定していません。
- 日経新聞など会員限定記事は、タイトルまでしか取得できない想定です。

## セットアップ

```bash
pip install -r requirements.txt
```

## 使い方

```bash
# 各ソースの疎通確認（ファイルは作らない。まずはこれで動作確認）
python main.py check

# 一部の新聞社だけ確認
python main.py check --only 朝日新聞 毎日新聞

# 全ソースを取得して output/YYYY-MM-DD.md と .json を生成
python main.py run

# 対象を絞る／日付を指定する
python main.py run --only 朝日新聞 読売新聞 --date 2026-07-21
```

## 新聞社を追加・修正する

`sources.yaml` に1エントリ追加するだけで対応できます。

```yaml
- name: 新聞社名
  category: 社説            # その社での呼称（産経は「主張」など）
  index_url: https://.../editorial/   # 社説一覧ページ
  item_selector: "li.article"          # 一覧内の1記事を指すセレクタ
  title_selector: "h3"                 # タイトル要素（item内の相対セレクタ）
  link_selector: "a"                   # リンク要素
  date_selector: "time"                # 日付要素（任意）
  verified: false
```

セレクタは実際のページの HTML を見ながら調整してください
（ブラウザの開発者ツールで一覧ページを開き、記事1件を囲む要素を探すのが早いです）。

## 定期実行したい場合

このリポジトリ自体には定期実行の仕組みは含めていません。GitHub Actions の
`schedule` トリガーや、自分のマシンの cron から `python main.py run` を
呼び出す形で定期実行を追加できます。
